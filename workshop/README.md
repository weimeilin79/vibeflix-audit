# Vibeflix Workshop — Build an Enterprise Multi-Agent Mesh with ADK

A hands-on workshop that builds a real, secured, multi-agent system on Google Cloud —
Google's **Agent Development Kit (ADK)**, **Model Context Protocol (MCP)** tool servers, and
**Agent Platform** (Agent Runtime, Agent Identity, Agent Gateway, Agent Registry).

You'll deploy the mesh one agent at a time, and each agent teaches a distinct concept — so by
the end you understand not just *how* to wire agents together, but *why* each piece is shaped
the way it is.

> **New to ADK?** That's the assumed starting point. Concepts are introduced before you use
> them; you don't need prior agent experience.

## What you'll build

The **Vibeflix licensing-audit mesh**: a streaming company licenses its characters to vendors
who manufacture merchandise, and this system automates the compliance review — brand, pricing,
vendor/legal clearance — that used to need human specialists. (The business story:
[`docs/01-the-story.md`](../docs/01-the-story.md).)

## Conventions

Each step uses these markers, borrowed from the codelab format:

- 💡 **Concept** — the idea being taught
- 💻 **Run** — a command to run in your terminal
- 📝 **Look** — a file to read (the code is already in the repo; you deploy and understand it)
- 👀 **Verify** — how to confirm the step worked

## Prerequisites

- A Google Cloud project with **billing enabled**, and `Owner` (or equivalent) on it.
- **Cloud Shell** (recommended — everything is pre-installed) or a local shell with the tools
  the preflight checks: `gcloud`, `terraform`, `python3`, `jq`, `openssl`.
- This repo, cloned, with `deploy/.env` created (Step 1 walks you through it).
