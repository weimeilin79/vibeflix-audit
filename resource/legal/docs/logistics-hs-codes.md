# Logistics — Customs / HS Tariff Codes (working sheet)

Maintained by: Kenji Watanabe (Logistics) · updated ad-hoc, no version control sorry

Legal files a customs **recordation** (trademark + HS code, per territory) before we
ship. If you skip the recordation the goods get held/seized at the border. Grab the code
for the category from here:

| Product category        | HS code      | Notes                                        |
|-------------------------|--------------|----------------------------------------------|
| Vinyl Figures           | `9503.00.00` | toys, general                                |
| Action Figures          | `9503.00.00` | same bucket as vinyl                         |
| Plush                   | `9503.00.41` | stuffed toys — different sub-heading         |
| Blind Box               | `9503.00.00` | classify by contents; usually the toy code   |
| Apparel                 | `6109.10.00` | knit t-shirts; other apparel varies          |
| Resin Statues           | `9503.00.00` | "collectible" grey area, sometimes `9618.00` |
| Premium Collectibles    | `9503.00.00` | treat as toys unless told otherwise          |

If a category isn't listed, ping me — do NOT guess a code, wrong classification = customs
fines. (Yes this should be in a real system. It is a markdown file. I know.)
