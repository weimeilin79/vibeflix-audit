# deploy/requirements.lock.txt — the EXACT dependency tree the workshop installs.
#
# Why a lock file: agents/requirements.txt and the two deploy/requirements-*.txt files use
# `>=` ranges, so two people running the workshop a week apart resolve different trees. That
# is how a rehearsal passes and the live session fails. init.sh installs THIS file instead,
# so every attendee gets byte-identical versions.
#
# Generated for PYTHON 3.12 (Cloud Shell's version). Regenerate after changing any
# requirements file — from the repo root, with uv installed:
#
#   uv pip compile --python-version 3.12 --prerelease=if-necessary-or-explicit \
#     agents/requirements.txt deploy/requirements-legal-rag.txt deploy/requirements-deploy.txt \
#     -o deploy/requirements.lock.txt
#
# NOTE the prerelease flag: `--prerelease=allow` (the obvious choice, since ADK 2.0 is pre-GA)
# also drags in a BETA pydantic (2.14.0b1) and other unrelated pre-releases. The flag above
# takes pre-releases only where a package genuinely has no stable release — which here is just
# the two opentelemetry-exporter-gcp-* alphas that google-cloud-aiplatform[agent_engines]
# pins directly.
#
# This lock does NOT cover: the agents' own manifests (agents/<name>/requirements.txt, which
# Agent Runtime installs IN THE CLOUD), terraform, or agents-cli — those are pinned in init.sh.
#
