# deploy/requirements.lock.txt — the EXACT dependency tree the workshop installs.
#
# Why a lock file: the requirements files it is built from use `>=` ranges, so two people
# running the workshop a week apart resolve different trees. That is how a rehearsal passes and
# the live session fails. init.sh installs THIS file instead, so every attendee gets identical
# versions.
#
# Covers SIX inputs — the agents, the two deploy-only sets, AND the three MCP servers. The MCP
# servers matter because run_local.sh runs them from this venv for the local Dev UI sections;
# leaving them out fails at import (`No module named 'spellchecker'`) the moment an agent tries
# to load its tools.
#
# Generated for PYTHON 3.12 (Cloud Shell's version). Regenerate after changing any input:
#
#   uv pip compile --python-version 3.12 --prerelease=if-necessary-or-explicit \
#     agents/requirements.txt deploy/requirements-legal-rag.txt deploy/requirements-deploy.txt \
#     mcp_servers/mcp_brand_style/requirements.txt mcp_servers/mcp_licensing/requirements.txt \
#     mcp_servers/mcp_market/requirements.txt \
#     -o deploy/requirements.lock.txt
#
# NOTE the prerelease flag: `--prerelease=allow` (the obvious choice, since ADK 2.0 is pre-GA)
# also drags in a BETA pydantic and other unrelated pre-releases. The flag above takes
# pre-releases only where a package has no stable release at all.
#
# Does NOT cover: the agents' own manifests (agents/<name>/requirements.txt, installed by Agent
# Runtime IN THE CLOUD), terraform, or agents-cli — those are pinned in init.sh.
#
